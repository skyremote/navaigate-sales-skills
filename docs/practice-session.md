# A practical first session

Aim: each person runs one useful workflow, checks its evidence and can repeat it without re-explaining the method. Work in the product you already have approved. Do not make installing a new IDE the first exercise.

## 1. See a complete task — five minutes

The facilitator opens Meeting Prep and uses its synthetic example. Show the request, the source and the resulting brief side by side. Ask: “Which sentence can we check? What is still unknown?”

Explain only the parts visible in the task: the skill is the saved method, the tool gets information, and the output is what we inspect. A file of instructions does not connect an account. Repeat the same request with a new input to show reuse.

## 2. Do one task yourself — ten minutes

Choose a skill from the README. First try its synthetic example. Then, if you have an approved connection, try a small real task in your own private workspace. If connection setup is blocked, use an approved file; complete the task before troubleshooting the whole environment.

Do not share a live mailbox or customer record on a projected screen without the right context and permission. Practice examples require neither.

## 3. Check and correct — five minutes

Answer together:

- What outcome did you ask for?
- What did the assistant actually read?
- Which claim is supported, which is inferred, and what is missing?
- Did it change an external system or just produce a proposal?
- What would you correct before using it?

Keep one correction with the result. With Build My Voice, edit the three test drafts; that feedback becomes part of your private writing profile.

## 4. Repeat — five minutes

Run the same skill with a different synthetic example or approved customer. Change the input, keeping the method. Then ask the assistant to explain in three sentences what it did and how it checked it.

Success is a useful output you understand and can repeat. Move on to a second skill after that. Model selection, hooks, complex folder systems and custom servers can wait until there is a task that needs them.
